# My Day v2

PWA personal de organización con estética editorial/chica cool basada en el icono proporcionado.

Incluye ropa, calendario mensual indefinido, rutinas, horario, estudios, apuntes con fotos, favoritos, historial y almacenamiento local.

## GitHub Pages
Source: Deploy from a branch → `main` → `/ (root)`.

## Instalación en iPhone
Abrir la URL publicada en Safari → Compartir → Añadir a pantalla de inicio.

## Nota sobre notificaciones
El navegador puede pedir permiso para notificaciones, pero los recordatorios push programados incluso con la app cerrada requieren un servicio de push/backend adicional. GitHub Pages por sí solo solo sirve los archivos estáticos.
